# NowChameh | نوچامه

مجموعه‌ای آزاد و ساختاریافته از اطلاعات شاعران و آثار شعر نو فارسی.

## درباره پروژه

NowChameh با هدف گردآوری، سازمان‌دهی و ارائه اطلاعات شاعران معاصر فارسی و آثار آن‌ها ایجاد شده است.

این پروژه تلاش می‌کند داده‌های شعر نو فارسی را در قالبی استاندارد، ساده و قابل استفاده برای توسعه‌دهندگان و علاقه‌مندان به ادبیات فارسی فراهم کند.

## ساختار پروژه

```text
NowChameh/
├── data/
│   ├── poets.json
│   └── poems.jsonl
├── schema/
│   ├── poet.schema.json
│   └── poem.schema.json
└── README.md
```

## ساختار داده‌ها

### شاعران — poets.json

اطلاعات هر شاعر شامل موارد زیر است:

| فیلد | توضیحات |
|---|---|
| id | شناسه یکتای شاعر |
| name | نام شاعر |
| bio | زندگی‌نامه |
| birth_year | سال تولد |
| death_year | سال وفات |

### شعرها — poems.jsonl

هر خط از این فایل شامل اطلاعات یک شعر است.

| فیلد | توضیحات |
|---|---|
| id | شناسه یکتای شعر |
| poet_id | شناسه شاعر |
| title | عنوان شعر |
| collection | نام کتاب یا مجموعه |
| form | قالب شعر |
| stanzas | بندها و سطرهای شعر |
| source | منبع دریافت شعر |

### قالب‌های پشتیبانی‌شده

- `nimaee` — شعر نیمایی
- `free_verse` — شعر سپید و آزاد
- `modern_ghazal` — غزل معاصر
- `chaharpareh` — چهارپاره
- `other` — سایر قالب‌ها

## اعتبارسنجی داده‌ها

ساختار اطلاعات شاعران و شعرها با استفاده از JSON Schema و استاندارد Draft 2020-12 تعریف شده است.

فایل‌های اعتبارسنجی:

- `schema/poet.schema.json`
- `schema/poem.schema.json`

## وضعیت پروژه

پروژه در مرحله توسعه اولیه و آماده‌سازی ساختار داده‌ها قرار دارد.

## مشارکت

پیشنهادها و مشارکت‌های مرتبط با گردآوری و استانداردسازی داده‌های شعر نو فارسی مورد استقبال هستند.
